# Python Implementation — Dash Cell Billing System

This module implements the billing system designed in the flowcharts and pseudocode.

## Features
- Modular billing function (`compute_bill`)
- Multi-customer processing
- Sentinel-controlled loop (999 to exit)
- Conditional filtering:
  - Messages > 100
  - Bill > $10
  - Specific area code

## How to Run

```bash
python3 dash_cell_system.py
```
